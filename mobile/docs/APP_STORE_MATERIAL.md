# 律所办公系统 移动端 · 上架材料包

## 一、应用简介（上架时直接复制）

**应用名称**：律所办公系统

**一句话简介**：面向律师事务所的一体化移动办公平台，案件、客户、日程、审批随时管，内置 AI 助手。

**应用描述**（上架详情页用）：

律所办公系统是专为律师事务所打造的移动办公平台，与电脑端数据实时同步，让律师随时随地把案子管起来。

核心功能：
- 工作台：案件、客户、待审批、日程一屏掌握
- 案件管理：立案建档、状态流转、进程留痕，原告被告清晰可查
- 客户管理：客户档案、联系人、跟进记录，法律顾问单位（VIP）单独归类
- 日程安排：开庭、会议、任务、提醒，按月浏览、及时提醒
- 审批流程：用章、请假、报销、立案线上审批，秒级流转
- 工时计费：在线记工时、提交审核、账单收款
- 知识库：办案经验、法规、文书模板沉淀复用
- AI 助手：查数据、起草文书、联网检索，写操作需人工确认，安全可控

数据加密传输、按角色分权限，律师只能看到自己权限内的数据。支持私有化部署，数据不出所。

## 四、打包 + 上架步骤

**第 1 步：打包 apk**
1. 下载 HBuilderX，打开 `lawfirm/mobile` 目录
2. `manifest.json` → 基础配置 →「重新获取」DCloud AppID
3. App 图标配置 → 上传 `icon-1024.png`
4. 「发行」→「原生App-云打包」→ Android → 打 apk

**第 2 步：提交华为市场**
1. 登录 AppGallery Connect，进入你已创建的华为 AppID 对应应用
2. 上传 apk
3. 填写：应用名称「律所办公系统」、简介（本文档）、图标（icon-512.png）、截图、隐私政策 URL、软著、备案号
4. 提交审核

---

## 五、注意事项

1. 首次上架审核可能要求修改（比如隐私政策细节、权限说明），按驳回意见改即可。
2. 软著是最大时间成本，建议尽早启动申请/代办。
3. 上架前先在真机测一遍：登录、建案件、记工时、传头像、日程、审批，确保无崩溃。
