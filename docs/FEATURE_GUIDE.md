# 第一部分：系统概述

律所数字化办公系统是面向 20–100 人律师事务所的一体化办公平台，覆盖案件、客户、计费、文档、日程、审批、知识库与经营统计全流程，并内置 **AI 智能助手**（基于大语言模型，可查询/操作系统数据，写操作需人工确认）。

**访问方式**：

| 方式 | 说明 |
| --- | --- |
| 网页端 | 浏览器访问系统地址登录使用 |
| 桌面客户端 | Windows 安装程序，独立窗口 + 系统托盘 + 开机自启 |
| PWA | 浏览器"安装应用"（需 HTTPS，见部署文档） |

**账号体系**：每人一个独立账号，登录后按角色与数据归属显示各自可见内容。

# 第二部分：功能维度

## 1. 登录与账号安全

- 用户名 + 密码登录，密码 BCrypt 加密存储
- 登录后签发 JWT 令牌（默认 12 小时有效）
- 右上角可修改自己的密码
- 管理员可对成员：创建账号、重置密码、停用/启用

## 2. 工作台（Dashboard）

登录后首页，展示待办与关键指标：

| 角色 | 展示内容 |
| --- | --- |
| 管理员 / 合伙人 | 案件总数、办理中、已结案、客户总数、待审批、待审核工时、本月营收、我的在办案件、即将到来日程、最近案件 |
| 律师 / 助理 / 行政 | 我的在办案件、即将到来日程、我的待审核工时（个人视角，不展示全所经营数据） |

提供「待办提醒」快捷入口（待审批、待审核工时、即将到来日程）。

## 3. AI 助手（重点模块）

- 流式对话，支持 Markdown 排版、代码高亮、工具调用步骤卡片
- **查询类**：案件、客户、工时、日程、审批、知识库、文档、经营概况
- **起草类**：律师函、起诉状、合同等文书起草（需律师审核后使用）
- **联网搜索**：最新法律法规、司法解释、判例、新闻（附来源链接）
- **办理类（写操作）**：新建/修改案件、客户、工时、账单、日程、审批、知识库、成员等；**所有写操作需在"待确认"卡片上人工确认后才执行**，系统**不提供删除功能**
- **模型设置**：每位用户可自选 LLM 厂商（DeepSeek/通义/智谱/Kimi/OpenAI/自定义）并填写自己的 API Key（加密存储），未配置时不可调用
- 左侧会话历史可新建、重命名、删除

> 详见《AI 助手使用说明（员工版）》。

## 4. 案件管理

- 立案、承办、进程跟踪、状态流转
- 案号自动生成（如 `LF2026-0001`）
- 字段：案号、名称、客户、类型（民事/刑事/行政/商事/劳动争议/知识产权/婚姻家事/其他）、优先级、主办律师、协办律师、受理法院、标的额、立案日期、结案日期、案情摘要、办理结果、收费金额
- 状态流转：待立案 → 办理中 → 暂停 → 已结案 → 已归档（结案时记录结果与结案日期，自动写入进程日志）
- 进程记录：每次状态变更、办理进展自动留痕
- 权限：仅主办律师可编辑/变更状态/删除（管理员/合伙人除外）；协办律师可查看与记录进展

## 5. 客户管理 CRM

- 客户档案（个人/企业）：名称、类型、证件号、行业、地址、电话、邮箱、分级（A/B/C）、来源、负责人、备注
- 联系人管理：姓名、电话、邮箱、职位、是否主要联系人
- 跟进记录：方式（电话/拜访/邮件/微信/会议/其他）、内容、下次跟进日期
- 关联统计：该客户名下的联系人数量、案件数量
- 权限：仅负责人（ownerId）可见/编辑（管理员/合伙人除外）

## 6. 工时计费

**工时记录**：
- 字段：关联案件、工作日期、工时（小时）、费率、金额（=工时×费率）、工作内容、状态
- 状态：已提交（待审核）→ 已审核 → 已开票
- 权限：只能给自己主办/协办的案件记工时；非管理员只能看/改自己的工时

**账单管理**：
- 将同一客户的**已审核工时**打包生成账单（草稿 → 已开票 → 已收款 → 已作废）
- 账单编号自动生成（如 `INV2026-0001`）
- 作废账单会释放工时恢复为已审核
- 权限：创建账单、开票/收款/作废仅合伙人/管理员；普通用户仅见自己客户相关账单

## 7. 文档中心

- 多级目录（目录树）
- 文件上传/下载、多版本管理（版本号递增、版本历史）
- 文档分类：合同、证据材料、裁判文书、法律文书、其他
- 文档可关联案件或客户
- 上传格式白名单：pdf/doc/docx/xls/xlsx/ppt/pptx/txt/md/csv/图片/压缩包等
- 权限：上传者、关联案件成员、关联客户负责人可访问；管理员/合伙人全可；仅上传者/管理员可删除

## 8. 日程安排

- 月/周/日视图
- 事件类型：开庭、会议、任务、提醒
- 字段：标题、类型、开始/结束时间、地点、说明、关联案件、参与人
- 权限：可查看自己创建的或自己参与的日程；仅创建者可修改/删除

## 9. 审批流程

- 审批类型（模板）：用章申请、请假申请、报销申请、立案审批、其他
- 发起 → 审批（通过/驳回，附意见）→ 归档；可撤销自己提交的待审批单
- 审批人必须是合伙人或管理员
- 权限：普通用户看"我提交的"；合伙人/管理员看全部并可审批

## 10. 知识库

- 分类：办案经验、法律法规、文书模板、培训资料、其他
- 文章：标题、分类、正文、标签、浏览量、发布/草稿
- 权限：所有人可见已发布文章；作者可管理自己的草稿；管理员可见全部

## 11. 统计报表（仅管理员 / 合伙人）

- 案件类型分布
- 近 6 个月新增案件与营收趋势
- 近 30 天律师工时排行

## 12. 成员管理（仅管理员）

- 成员列表（按姓名/用户名/角色检索）
- 创建账号（用户名、初始密码、姓名、角色、部门、职务、邮箱、电话）
- 修改成员信息、重置密码、停用/启用

# 第三部分：角色维度

系统内置 5 种角色：

| 角色 | 代码 | 定位 |
| --- | --- | --- |
| 系统管理员 | ADMIN | 系统运维 + 全所数据 + 成员管理 |
| 合伙人 | PARTNER | 全所数据 + 审批 + 计费/经营 |
| 执业律师 | LAWYER | 自己承办的案件与客户 |
| 律师助理 | PARALEGAL | 协助律师办理事务 |
| 行政人员 | STAFF | 行政、文档、日程、审批等 |

## 3.1 系统管理员（ADMIN）

**可见菜单**：全部（含成员管理、统计报表）。

**数据权限**：全所数据（案件、客户、文档、账单、工时、知识库全部可见）。

**关键操作**：
- 成员管理：创建/修改/停用账号、重置密码
- 查看全所经营报表与工时排行
- 案件/客户/文档/账单的所有操作
- 审批（作为审批人之一）
- AI 助手全量工具

**典型场景**：新员工入职建账号、重置忘记的密码、查看全所经营数据、停用离职人员账号。

## 3.2 合伙人（PARTNER）

**可见菜单**：全部（含统计报表，不含成员管理）。

**数据权限**：全所数据（与管理员一致）。

**关键操作**：
- 审批（审批人）：处理用章/请假/报销/立案等审批单
- 工时审核：审核/驳回员工提交的工时
- 账单：创建账单、开票、收款、作废
- 查看经营统计与工时排行
- 案件/客户/文档/日程/知识库全量操作
- AI 助手全量工具

**典型场景**：审批立案、审核工时、开票收款、查看经营报表。

## 3.3 执业律师（LAWYER）

**可见菜单**：工作台、AI 助手、案件、客户、工时、账单、文档、日程、审批、知识库（无统计报表、无成员管理）。

**数据权限**：仅自己**主办或协办**的案件、自己**负责**的客户、自己的工时、自己创建/参与的日程、自己上传或关联的文档。

**关键操作**：
- 办案：新建案件、记录进展、变更自己主办案件的状态
- 客户：管理自己负责的客户与跟进记录
- 工时：给自己主办/协办的案件记工时、提交审核
- 发起审批（如立案审批、用章）
- 知识库：发布/修改自己的文章
- AI 助手：查询自己权限内数据 + 办理写操作（需确认）

**典型场景**：日常办案、记工时、跟进客户、发起审批、用 AI 起草文书。

## 3.4 律师助理（PARALEGAL）

**可见菜单**：与律师相同。

**数据权限**：仅自己**主办或协办**的案件、自己**负责**的客户、自己的工时/日程/文档。

**关键操作**：
- 协助主办律师记录案件进展、整理文档
- 客户跟进记录
- 记录工时（需被设为主办/协办律师才可记对应案件）
- 发起审批、安排日程
- 知识库、AI 助手

**典型场景**：协助律师整理卷宗、记跟进、录工时、跑流程。

## 3.5 行政人员（STAFF）

**可见菜单**：工作台、AI 助手、客户、工时、文档、日程、审批、知识库（无案件管理相关数据，除非被指定为主办/协办）。

**数据权限**：自己负责的客户、自己的工时/日程/文档；案件仅在作为主办/协办时可见。

**关键操作**：
- 客户档案与跟进（自己负责的）
- 发起请假/报销/用章等审批
- 文档上传、日程安排
- 知识库、AI 助手

**典型场景**：行政事务、用章/报销审批、档案与文档管理。

# 第五部分：AI 助手专项说明

## 5.1 能力范围

- **可查询**：案件、客户、工时、日程、审批、知识库、文档、经营概况（均在本人权限内）
- **可起草**：律师函、起诉状、合同、申请书等（仅供参考，须律师审核）
- **可联网**：最新法律法规、司法解释、判例、新闻（附来源链接）
- **可办理（写操作）**：新建/修改案件、客户、工时、账单、日程、审批、知识库、成员（管理员）等；**全部需人工确认**；**无删除能力**

## 5.2 安全机制

1. **数据范围**：AI 与普通界面权限完全一致，只能操作当前登录人权限内的数据
2. **人工确认**：所有写操作先生成"待确认"卡片，用户点"确认执行"后才真正落库
3. **加密**：用户自配的 API Key 以 AES-GCM 加密存储，仅本人可见（界面显示掩码）
4. **无删除**：系统刻意不向 AI 提供删除工具

## 5.3 模型配置

- 默认：未配置个人 Key 的用户无法调用 AI
- 个人配置：AI 助手右上角「模型设置」→ 选厂商 + 填自己的 API Key
- 厂商：DeepSeek / 通义千问 / 智谱 GLM / Kimi / OpenAI / 自定义（OpenAI 兼容接口）
