# 用户使用手册

## 登录与账号

- 使用管理员分配的账号密码登录；首次登录建议立即修改密码（右上角头像 → 修改密码）。
- 角色权限：
  - **系统管理员**：全部功能 + 成员管理 + 审批模板维护
  - **合伙人**：全部业务功能 + 工时审核 + 账单管理 + 全部审批单查看
  - **执业律师/助理**：业务功能 + 自己的案件/工时/申请
  - **行政人员**：业务功能 + 发起审批

## 工作台

- 顶部统计卡：案件总数、办理中、已结案、客户数、待审批、待审核工时、我的在办案件、本月营收。
- 待办提醒：点击可直接跳转到对应模块处理。
- 最近案件：点击进入案件详情。

## 案件管理

- **立案**：点击「立案」，选择客户、案件类型、主办/协办律师、法院、标的额等，保存后自动生成案号（如 LF2024-0001）并记录立案进程。
- **案件详情**：查看基本信息、添加进程记录（开庭、送达、和解等）、变更状态。
- **状态流转**：待立案 → 办理中 → 暂停 → 结案（填写办理结果与结案日期）→ 归档。
- 结案/归档案件不可再编辑；办理中案件不可删除。

## 客户管理

- 新增客户：个人/企业，支持证件号、行业、来源、负责人、客户分级（A 重要 / B 普通 / C 潜在）。
- 客户详情：维护联系人与跟进记录；跟进记录支持下次跟进日期，便于客户回访管理。

## 工时与账单

- **记工时**：选择案件、日期、工时、费率（可选），填写工作内容。提交后由合伙人/管理员审核。
- **工时状态**：待审核 → 已审核 → 已开票。非管理员默认只看自己的工时。
- **生成账单**：合伙人/管理员从「已审核」工时中选择同一客户的多条记录生成账单（草稿）。
- **账单流转**：草稿 → 开票 → 收款；作废账单会释放关联工时。

## 文档中心

- 左侧目录树管理多级目录；上传时可按目录、案件、分类组织。
- 支持多版本：对同一文档上传新版本，可随时下载任意历史版本。
- 下载链接自动携带登录令牌，无需重复登录。
- 删除文档会删除全部历史版本，请谨慎操作。

## 日程安排

- 支持月/周/日视图切换，点击日期空白处或「新建日程」创建。
- 类型：开庭（红色标识）、会议、任务、提醒；可关联案件并邀请参与人。
- 仅创建者或管理员可编辑/删除。

## 审批流程

- **发起申请**：选择审批类型（用章/请假/报销/立案等）、填写内容、指定审批人（合伙人或管理员）。
- **我的申请**：查看自己提交的单据，待审批状态可撤销。
- **待我审批**：合伙人与管理员在此处理审批（通过/驳回，需填写意见）。
- 管理员可在「审批模板管理」中维护模板（新增/编辑/停用/删除）。

## 知识库

- 发布文章：办案经验、法律法规、文书模板、培训资料。
- 草稿仅作者与管理员可见；发布后全员可见。
- 列表卡片式展示，支持按分类/关键词搜索。

## 统计报表

- 案件类型分布（饼图）、近 6 个月新增案件与营收（柱线图）、近 30 天律师工时排行（条形图）。
- 数据明细面板展示完整数字，供导出核对。

## 成员管理（仅管理员）

- 新增成员：设置用户名、初始密码、角色、部门、职务。
- 停用/启用账号；停用后无法登录。
- 重置密码：为忘记密码的成员设置新密码。

## 常见操作提示

- 列表页的「查询」按钮与分页联动；搜索框支持回车触发查询。
- 表格行点击进入详情（案件/客户）。
- 金额单位均为人民币（元），工时单位为小时。
