# AI 助手使用说明（员工版）

> 适用版本：律所数字化办公系统 v1.x · 最后更新：2026-08-18

AI 助手是系统内置的智能工作伙伴：它**直接连接所内的真实数据**（案件、客户、工时、日程、审批、文档、知识库），既能"查"，也能在**你确认后**帮你"办"。

---

## 一、怎么进入

1. 浏览器打开系统地址（或双击桌面「律所办公系统」图标），用你的账号登录。
2. 点击左侧菜单栏的 **「AI 助手」**。
3. 在底部输入框打字，按 `Enter` 发送（`Shift + Enter` 换行），即可开始对话。

> 首次使用建议点击右上角 **「模型设置」** 完成模型配置（见第三节），否则使用系统默认模型。

## 二、它能帮你做什么

### 查询类（直接回答，无需确认）

| 你可以这样问 | 示例 |
| --- | --- |
| 案件情况 | "我的案件有哪些？""查一下 LF2026-0002 的进展" |
| 客户信息 | "搜一下华晨科技的档案""陈建国的跟进记录" |
| 工时 | "我这周记了多少工时？""我上个月工时汇总" |
| 日程 | "明天我有什么安排？""未来 7 天有哪些开庭？" |
| 审批 | "待我审批的有哪些？""我提交的审批怎么样了？" |
| 知识库 | "检索一下合同审查要点""有没有民间借贷相关的文书模板？" |
| 文档 | "帮我找'起诉状'相关的文档" |
| 经营数据 | "看一下经营概况"（仅管理员/合伙人） |

### 起草类（AI 直接生成文字）

- "根据案件 LF2026-0002 的信息，起草一份律师函"
- "写一份借款纠纷的起诉状，当事人是陈建国"

> ⚠️ 起草文书仅供参考，**必须由执业律师审核确认**后才能对外使用。

### 联网搜索（最新法律法规 / 新闻 / 判例）

- "联网搜索：新公司法注册资本五年认缴的最新规定"
- "搜一下最新的劳动争议司法解释"

AI 会自动联网检索，并在回答末尾附上**来源链接**。内部知识库查不到的，它也会尝试联网。

### 办理类（需要你点"确认执行"才真正生效）

| 模块 | 能做的 |
| --- | --- |
| 案件 | 新建案件、修改案件、变更状态、记录办理进展 |
| 客户 | 新建客户、修改档案、添加跟进记录、添加/修改联系人 |
| 工时计费 | 记录工时、修改工时；创建账单、账单状态变更（合伙人/管理员） |
| 日程 | 创建日程、修改日程 |
| 审批 | 发起审批、审批通过/驳回、撤销自己提交的审批 |
| 文档 | 新建目录 |
| 知识库 | 发布文章、修改自己的文章 |
| 成员 | 新建成员、修改成员、重置密码（仅管理员） |

**它不会做的**：删除任何数据（系统中不提供删除工具）；上传/替换文件本体（需要你到"文档中心"手动操作）。

## 三、模型设置（建议首次使用时配置）

系统支持你使用**自己的大模型账号**，费用由你自己承担，不占用律所公用额度：

1. 点击 AI 助手页面右上角 **「模型设置」**。
2. **厂商**：推荐 DeepSeek；也可选通义千问、智谱、Kimi、OpenAI 或自定义（OpenAI 兼容接口）。
3. 选择厂商后接口地址与模型名称会自动填好（一般不用改）。
4. **API Key**：在对应厂商官网注册并创建 API Key（如 DeepSeek：platform.deepseek.com → API Keys），粘贴进去。
5. 点 **「保存」**。之后你的对话就走你自己的账号。

- Key **加密保存**，仅你本人账号可见，界面只显示掩码（如 `sk-t****abcd`）。
- 想改 Key：重新打开模型设置，填入新 Key 保存（留空则保持原 Key 不变）。
- 想恢复系统默认：点 **「清除配置」**。

> 各厂商工具调用（查案件、记工时等）兼容性略有差异，稳定性排序：DeepSeek 最佳。

## 四、重要：写操作的"二次确认"

为了防止误操作，**所有写操作都不会立即执行**：

1. 你让 AI 办一件事（如"帮我记 2 小时工时"）；
2. AI 会生成一张**黄色"待确认"卡片**，上面写明它准备做什么、参数是什么（点卡片可展开查看细节）；
3. 你点 **「确认执行」** → 才真正写入系统；点 **「取消」** → 什么都不做。

- 卡片在**刷新页面后依然存在**（系统会记住未处理的操作），请及时处理，避免遗忘。
- 权限与你在普通页面上操作完全一致：**不属于你权限范围的操作会被系统拒绝**。

## 五、每个人只能看到自己权限内的数据

AI 助手严格遵守系统权限：

| 角色 | 数据范围 |
| --- | --- |
| 管理员 / 合伙人 | 全所数据 |
| 律师 / 助理 / 行政 | 仅自己主办/协办的案件、自己负责的客户、自己的工时与日程等 |

AI 不会回答超出你权限范围的数据。

## 六、会话管理

- 左侧是**对话历史**，点击可继续之前的对话；AI 记得上下文。
- 点 **「新建」** 开一个全新对话。
- 鼠标移到某个对话上，可 **重命名**（✏️）或 **删除**（🗑️）。

## 七、常见问题

**Q：AI 回答很慢？**
A：复杂问题（多步查数据 + 起草长文）需要几十秒，属正常。页面会显示"思考中…"，中途可点「停止」。

**Q：为什么有时提示"操作失败"？**
A：可能是权限不够、数据状态不允许（如已结案案件不可修改），或你的模型 Key 余额/额度不足。看卡片里的错误信息即可。

**Q：为什么不能删除数据？**
A：出于安全考虑，系统刻意不向 AI 提供删除功能。需要删除请到对应功能页面由有权限的人操作。

**Q：AI 说错了怎么办？**
A：AI 可能出错（尤其是法律条文）。重要结论请以系统内实际数据为准，法律意见请以执业律师判断为准；联网检索的结论请点开来源链接核对。

**Q：我不想用自己的 Key，可以吗？**
A：可以。不配置模型设置即使用系统默认模型，不影响使用。

## 八、使用建议

1. 问得越具体，答得越准（带上案号、客户名、日期）。
2. 办事情用自然语言描述即可，例如："为 LF2026-0002 记 2.5 小时工时，内容：会见当事人，日期今天"。
3. 涉密事项照常在系统内操作，AI 与系统权限一致，不会越权泄露。
4. 遇到问题反馈给系统管理员。
