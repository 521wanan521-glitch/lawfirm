# 律所数字化办公系统 · 演示视频脚本

> 视频总时长约 **8–10 分钟**，面向律所管理层与全体律师，用于系统上线培训或对外介绍。
> 录制前请先按本文「录制准备」配置好演示账号与数据，并按分镜逐段录制、后期配音。

---

## 一、录制准备

| 项目 | 说明 |
| --- | --- |
| 环境 | 已部署的系统（Docker 或本地），推荐使用 1920×1080 全屏浏览器 |
| 账号 | `admin / admin123`（管理员，演示成员管理）；`lawyer1 / lawyer123`（律师，演示业务操作） |
| 演示数据 | 首次启动自动内置 2 个客户、1 个案件、1 篇知识文章、1 条日程；如已清空可手动补充 |
| 工具 | 录屏（OBS / 系统录屏）+ 麦克风；建议开启浏览器「隐藏个人书签栏」保持画面干净 |

---

### 场景 1 · 登录与工作台（0:15 – 1:00）

| 项 | 内容 |
| --- | --- |
| 画面 | 输入 `lawyer1 / lawyer123` → 点击登录 → 进入工作台 |

### 场景 2 · 案件管理（1:00 – 3:00）

| 项 | 内容 |

| 画面 | 左侧菜单点击「案件管理」→ 列表 → 点击「立案」 |
| 操作 | 1. 进入案件管理；2. 点击绿色「立案」按钮；3. 演示填写：选择客户、案件类型、主办/协办律师、法院、标的额；4. 保存 |
| 旁白 | 「案件管理是系统核心。点击立案，选择客户、案件类型和主办律师，填写标的额后保存，系统自动生成唯一案号，并记录一条立案进程。」 |

**画面要点**：保存后高亮显示自动生成的案号（如 `LF2026-0001`）。

| 项 | 内容 |
| --- | --- |
| 画面 | 点击案件行进入详情 → 添加进程 → 变更状态 |
| 操作 | 1. 点进案件详情；2. 点「添加进程」记录一次开庭/送达；3. 点「变更状态」把案件流转为「办理中」 |
| 旁白 | 「进入案件详情，可以随时补充进程记录，每一次状态变更都会自动留痕，形成完整的案件时间轴，方便团队协作和客户汇报。」 |

**画面要点**：滚动展示右侧时间轴的进程记录。

### 场景 4 · 工时与账单（4:00 – 5:30）

| --- | --- |

| 操作 | 1. 点「记工时」；2. 选择案件、日期、工时、费率、填写内容；3. 保存后点「提交」 |
| 旁白 | 「律师按案件记录工时，提交后由合伙人审核，费率自动计算出金额。」 |

| 项 | 内容 |
| --- | --- |
| 画面 | 切换到合伙人视角（重新登录 `partner / partner123`）→ 审核工时 → 生成账单 |
| 操作 | 1. 在工时列表点「通过」审核；2. 进入「账单管理」；3. 点「生成账单」，勾选已审核工时、选择客户、生成；4. 依次点「开票」「收款」 |

## 三、后期制作建议

- **字幕**：按旁白逐句配字幕，重点术语（案件、工时、账单、审批）可用高亮。
- **配乐**：轻柔商务背景音乐，音量低于人声。
- **剪辑**：每个场景之间加 0.5 秒淡入淡出转场。
- **封面**：使用登录页品牌截图 + 标题「律所数字化办公系统 · 使用演示」。
